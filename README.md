# Java Weather WebApp

A simple Java-based web application to check the current weather of any city using a weather API.

## Features
- Search weather by city name
- Shows temperature, humidity, wind speed, and weather conditions
- Simple and clean user interface
- Built with Java and web technologies

## Technologies Used
- Java
- Servlets / JSP (or Spring Boot if applicable)
- HTML, CSS, JavaScript
- JSON parsing (Gson / Jackson)
- OpenWeatherMap (or any weather API)
